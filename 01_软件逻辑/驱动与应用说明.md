# 软件逻辑：驱动与应用

## 唯一工程入口

打开 `STM32工程/MDK-ARM/DZXTSJ.uvprojx`。目标芯片为STM32F103RE，配置使用STM32F1xx_DFP 2.2.0和ARM Compiler 5.06 update 6。

保留STM32CubeMX/Keil标准目录，使工程路径仍然有效；没有为了分文件夹而重写学长程序。原程序把部分板级驱动和应用集中写在 `main.c`，实际边界如下。

| 层次 | 文件/函数 | 作用 |
|---|---|---|
| 应用入口 | `Core/Src/main.c`：`main` | 初始化，循环调度按键、姿态、探墙、迷宫控制、状态发送 |
| 迷宫应用 | 同文件：`Maze_Init`、`Maze_UpdateWalls`、`Maze_ComputeDistances`、`Maze_ChooseNextMove`、`Maze_Controller` | 地图、洪泛距离、下一步决策和状态机 |
| 运动应用 | 同文件：`Motion_Start*`、`Motion_Stop`、`Action` | 一格前进、左转、右转、掉头、停止 |
| 控制算法 | 同文件：`PID_Init`、`Angle_Control_Update`、定时回调内速度PID | 角度环、速度环及左右平衡 |
| 板级驱动 | 同文件：`Set_LeftLun_Duty`、`Set_RightLun_Duty`、`CGQ_Read`、`JY61P_Proc`、`Send_Debug_Data` | 电机输出、数字量传感器、姿态帧和状态上报 |
| 板级外设配置 | `Core/Src/gpio.c`、`tim.c`、`usart.c`、`adc.c`及对应头文件 | GPIO、PWM、编码器、串口和ADC初始化 |
| 引脚定义 | `Core/Inc/main.h` | 板级名称与STM32引脚对应 |
| 中断与系统 | `stm32f1xx_it.c`、`stm32f1xx_hal_msp.c`、`system_stm32f1xx.c`、启动汇编 | 硬件中断入口、启动、时钟 |
| 芯片驱动库 | `Drivers/STM32F1xx_HAL_Driver` | ST HAL/LL外设库 |
| 内核支持 | `Drivers/CMSIS` | ARM内核、编译器和芯片寄存器支持 |

## 图形界面编译步骤

1. 双击上述Keil工程。
2. 如果提示编译器不可用，在“Options for Target → Target”选择ARM Compiler 5.06 update 6。
3. 确认安装 `Keil::STM32F1xx_DFP@2.2.0`。本机已检测到。
4. 点击“Rebuild”重编译。输出窗口应为0错误、0警告。
5. Keil手动编译会在 `MDK-ARM/Build` 产生新结果；当前交付预编译固件位于本目录的 `固件/DZXTSJ.hex`。

更方便的方式：双击 `编译验证.vbs`，它在临时目录编译，成功后更新最终HEX和验证记录，不向工程内塞入一堆对象文件。

`DZXTSJ.ioc` 可用STM32CubeMX查看外设配置。自动重新生成代码可能更新库和生成区，应先另存工程再操作。

## 原始参数边界

保留学长原有PID、左右轮补偿、转向角度修正、每格256计数等参数，不宣称这些数值已适配你的未来小车。一次前进的距离、左右轮方向、红外触发距离和陀螺仪偏航正负号，必须到实物阶段分别标定。

## 小车本地操作

- KEY0：开始/停止自动迷宫模式。
- KEY1：非迷宫模式下切换直行、左转、右转、掉头、停止。
- KEY2：非迷宫模式下调整直行速度。

这些是源码定义的行为。未连接实物进行按键或电机试验。
