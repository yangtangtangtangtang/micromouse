# 上位机调试辅助

## 启动

- 双击 `离线演示.vbs`：不需要小车或串口，运行明确标注的样例轨迹。
- 双击 `启动上位机.vbs`：进入正常接收监控模式。
- 如果脚本宿主不可用，使用同名 `.cmd` 入口。
- 代码统一入口：`run.py`。`main.py` 是业务和界面实现，不作为本交付的独立启动入口。

只有一份业务主程序，版本号为 `3.4.2-course1`。保留作者署名；这是本次修订版，不冒充原发布安装包。

## 离线演示操作

1. 双击离线演示，等待约6秒。
2. 标题明确显示“非实车数据”。轨迹从(7,0)出发，含一次折返，到达中心格(4,3)。
3. 左侧“实时日志”查看以 `s,` 开头的接收内容。
4. 左侧“轨迹回放”点击“刷新列表”，选择原始轨迹，导出CSV或PNG。
5. 演示期间禁用真实串口连接，避免把样例与实物数据混合。重新启动“启动上位机”恢复串口监控。

样例文件为 `离线样例.txt`，每行使用与下位机一致的8字段状态协议。演示模拟字节输入，并不是STM32仿真器，也不会模拟PID、电机或真实串口硬件。

## 将来连接实物

1. 连接USB转TTL串口与小车USART3，确认逻辑电平与实物模块匹配，共地。
2. 电脑端选择设备管理器中实际出现的COM口。
3. 设置115200、8数据位、1停止位、无校验。
4. 点击连接。小车每约500ms发送一次状态。
5. 使用小车板载KEY0启动迷宫模式；电脑只负责监控。

**不要把上位机里原来存在的按钮当成已经完成的遥控功能。** 配套固件未实现指令接收，本整理版禁用了启动/停止/复位/救援/路径下发，并阻止原始发送函数误报成功。

## 协议

```text
s,X,Y,O,Angle,Front,Left,Right,Mode\r\n
s,7,0,0,0.0,1,1,0,1\r\n
```

| 字段 | 含义 |
|---|---|
| X、Y | 0～7整数格坐标；显示时加0.5，画到格子中心 |
| O | 0北、1东、2南、3西 |
| Angle | 下位机上报的有限角度数值 |
| Front、Left、Right | 0有墙，1无墙 |
| Mode | 0停止，1迷宫模式 |

协议没有电池电压、后传感器数值、轮速或PID参数。它们不能靠上位机自动补出来。

## 路径结果的含义

原始轨迹是接收到的位置历史。地图预估路径使用学长的BFS实现，把未观测的区域视作可通行，因此只用于分析。当前交付不把它称作“已验证最优路线”，也不将其下发小车执行。

轨迹回放的CSV坐标是画布中心坐标，可能含平滑插值；不应把每一行都当成小车走过一整格。

## 环境与VS Code

本机已配置 `.venv`，Python 3.11、NumPy 1.26.4、Matplotlib 3.8.4、PyQt5 5.15.11，全部依赖的精确版本保存在 `requirements.txt`。

VS Code打开本目录后：点击右下角Python解释器 → 选择本目录 `.venv/Scripts/python.exe` → 打开 `run.py` → 点击右上角运行按钮。不要选择原来的Anaconda基础环境，否则可能遇到NumPy与绘图库不兼容。

换电脑或移动到其他路径后，先运行 `安装运行环境.cmd` 重建环境；需安装Python 3.11并能访问Python包源。现有虚拟环境依赖本机Python安装，不能宣称它是跨电脑免安装程序。

用户设置和缓存存入本目录 `运行数据`，不读写学长应用原来的注册表设置。
