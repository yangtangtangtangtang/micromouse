# 版本选择和修改清单

## 版本冻结

| 对象 | 采用 | 不采用及原因 |
|---|---|---|
| 小车软件 | GitHub `DZXTSJ-Group01.zip`中的STM32F103RE数字量程序 | 原目录中的 `.o/.d/.crf/.axf/.hex` 是历史输出，不作为本次构建结果 |
| 上位机源码 | GitHub提交 `8ec56f9...` 的 `main.py`，整理修订为3.4.2-course1 | `restored_main.py`、`backupgif`、`SRC_Ver3.5.1`、`exam_testver`、`testscore` 均有空的 `_optimize_path`；多个文件来自反编译恢复，存在控制流缺失 |
| 上位机发布基线 | 作者3.4.2稳定版本的功能范围 | 4.x/5.0.1的界面和成绩榜不作为实车已验收功能；发布说明和期末Readme明确后期版本未经实物串口验证 |
| 硬件 | 期末备份“电脑鼠SYR-数字量.eprj” | 模拟量工程属于未调试稳定的后期方案；期末报告结论明确最终用数字量 |
| 硬件PDF | 共用的底盘原理图、PCB2、PCB3 | 备份中扩展主板原理图PDF、PCB1 PDF为模拟量版本，未混用 |

网页宣传、README、报告、源码和安装包并非完全一一对应，不能把最高版本号当成全系统最终可用版。本交付选择作者实际完成课设的方案，并独立验证交付副本能完成的流程。

## 实際源码对比验证

在同一套可用Python/Qt环境中，给原始 `main.py` 和原始 `restored_main.py` 输入同样7帧路径：

- `main.py`：终点显示(4.5,3.5)，记录7个格点，生成1条优化结果及3条回放。
- `restored_main.py`：终点显示仍停在(5.5,3.5)，记录格点数为0，无优化结果和回放，`_optimize_path`返回None。

这些是本次电脑侧直接测试结果，支持源码选择；不能反推原发布安装包也存在完全相同问题。

## 小车程序修订

1. `Core/Src/main.c` 增加 `<stdio.h>`、`<string.h>`，消除 `snprintf/strlen` 隐式声明。
2. `strlen` 的实参显式转换为 `const char *`，匹配标准库接口。
3. Keil工程编译器标识更新为本机安装的ARM Compiler 5.06 update 6 build 750；输出目录规范为Build，关闭浏览中间信息和空的编译后命令。

没有更改寻路、PID、转角、速度、传感器判定、引脚和串口协议。没有替换原始资料。新固件的源文件散列对应关系保存在 `固件与源码对应.json`。

## 上位机修订

1. 增加独立入口 `run.py`、本地INI设置、独立Python环境及双击启动脚本，避免污染既有环境。
2. 显式设置PyQt插件目录，解决本机Qt默认插件查找导致的初始化卡住。
3. 修复轨迹PNG导出调用不存在的 `draw_overlay`，改为实际存在的 `draw_selected`。
4. 终点结算移到位置与墙壁更新之后，确保原始回放包含最后的终点帧。
5. 校验字段数、空字段、坐标范围、朝向、传感器值、有限角度和模式；错误帧拒绝后继续接收。
6. 隐藏并禁用配套固件不支持的发送和小车遥控区域；发送入口显示范围说明，不再误报指令成功。显示电压“固件未上报”。
7. 增加明确标注的离线样例，经过同一接收与解析函数；演示期间隔离真实串口入口。
8. 保留BFS预估算法，将未知通道假设及结果类型说清楚；把点数显示为“点”，不把点数误写成运动步数。
9. 修正指南针绘制中0度=北、顺时针增加的旋转关系；未改变固件姿态解算或标定。
10. 收起无效控制后调整显示，避免传感器数值和按钮文字被压缩裁切。软件“文档”页显示本交付使用说明，禁用在线更新按钮，防止测试版本信息覆盖冻结版本。

## 保留的实际边界

- 下位机只有状态上报，没有遥控指令解析或接收优化路径。
- 固件参数仍是学长实物的经验值；本次未验证JY61P字节时序、编码器距离、运动精度和真实走迷宫。
- 位置每500ms上报一次，可能跳过中间格；上位机绘制插值不代表采到了那些格子的传感器数据。
- 地图预估路径包含“未知视为通路”的假设，不是可直接执行的已验证最优路线。
- 原始数字量EDA工程保留了内部未关联PCB3_1页面，但它不是交付选定的最终板。核心板原理图缺页这一原始资料问题已显式标明。
- 原期末报告带有概述性陈述、参数差异和后期代码片段，只用于版本证据和学习参考；具体程序行为以交付源码为准。

界面收尾：文档页改为读取随附使用说明；关闭冻结交付版的在线更新按钮；统一按钮文字与背景对比度，提高回放导出入口的可读性。
